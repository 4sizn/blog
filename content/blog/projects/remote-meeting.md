## 참여 맥락

리모트미팅 전면 리뉴얼에서 기존 jQuery UI를 React·TypeScript·Recoil 구조로 옮기는 작업에 참여했다. 기간은 2021년 6월부터 2022년 3월까지다. 이 글은 공개 가능한 포트폴리오 이력에만 근거하며, 회사 소스·내부 지표·비공개 설계 문서는 포함하지 않는다.

## 맡은 개발 범위

- 공용 컴포넌트와 Video 컴포넌트 개발
- 사용자 초대 흐름과 데이터 정규화
- Recoil 상태 관리에서 서비스 트랜잭션과 렌더링 비용을 고려한 구현

## 이력에서 읽는 기술적 전환

이 전환의 핵심은 화면을 jQuery로 직접 갱신하던 방식에서, 상태 변화가 React 렌더링으로 이어지는 모델을 만드는 일이었다. 초대·영상처럼 여러 화면이 같은 정보를 참조하는 흐름에서는 데이터 구조와 업데이트 시점을 함께 다뤄야 한다. 따라서 이 참여 기록은 단순 기능 목록 대신 공용 UI, 정규화, 상태 경계를 담당 범위로 남긴다.

## 기록의 한계와 현재 상태

보안·계약상 원본 코드와 운영 수치를 공개하지 않는다. 여기서 확인 가능한 사실은 역할, 기술 스택, 기간뿐이다. 향후 공개 가능한 코드나 설계 자료가 확보되면 동일한 제작기 템플릿에 따라 근거를 보강한다. [포트폴리오 요약](/projects/remote-meeting)을 확인할 수 있다.
