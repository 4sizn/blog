# 테스트 계획

> 근거: `requirements.md` 수용 기준 (FR 13건 · NFR 6건) · `design.md` 영향 범위

## 1. 범위와 성격

이 프로젝트의 산출물은 **문서·템플릿·skill·콘텐츠**이고 실행 코드는 스크립트 하나와 워크플로 하나다.
단위 테스트 프레임워크가 없는 저장소이므로 TC는 **명령 실행과 산출물 검사**로 구성한다.
"판정 가능한 명령 + 기대 출력"을 TC의 최소 단위로 삼는다.

자동화 가능 여부를 각 TC에 표시한다. 반복 실행할 값어치가 있는 것은 스크립트로 남길 후보다
(리뷰 지적 4 — 현재 검증 스크립트가 저장소 밖에 있다).
