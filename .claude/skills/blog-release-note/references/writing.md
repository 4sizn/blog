# 문장 쓰기 — humanize-korean 경유

릴리즈 노트 문장은 **초고 → humanize-korean 윤문 → 사실 대조 → 게시** 순서로만 만든다.
이 경유는 선택이 아니다. 한 줄짜리 패치 릴리즈에도 적용한다.

## 1. 초고

사실과 구조를 확정하는 단계다. 문체는 아직 신경 쓰지 않는다.

- 골격의 섹션 순서를 지킨다
- 각 문장의 근거를 안다 (릴리즈 본문 / 커밋 / 실제 확인한 동작)
- 근거가 없으면 그 문장을 쓰지 않는다. 섹션을 지운다

## 2. 윤문

```
Skill(skill: "humanize-korean:humanize-korean")
```

| 상황 | 지정 |
|------|------|
| 기본 | 그냥 호출한다. shim 이 light/standard/heavy 를 판단한다 |
| 중요한 릴리즈·긴 글 | "정밀 모드" 또는 `--strict` → heavy 고정 |
| 결과 등급이 C/D | heavy 로 재실행한다 |

스킬은 cwd 기준으로 `_workspace/{run_id}/` 를 만든다. `.gitignore` 에 등록돼 있으므로 저장소에 남지 않는다.
**run_id 를 기록해 둔다** — 나중에 어떤 윤문을 거쳤는지 되짚을 수 있어야 한다.

### 스킬이 없으면

`im-not-ai` 플러그인이 없거나 호출이 실패하면 **작업을 멈추고 사용자에게 알린다.**
직접 다듬어 우회하지 않는다. 우회를 한 번 허용하면 강제가 무의미해진다.

## 3. 사실 대조 — 윤문이 사실을 바꿨는지 본다

`humanize-korean` 은 "내용을 건드리지 않는다"고 명시하지만, 릴리즈 노트는 숫자 하나가 틀리면
무의미해지는 사실 문서다. 다음을 초고와 나란히 놓고 확인한다.

| 항목 | 예 |
|------|-----|
| 버전 | `v1.2.4` 가 `v1.2.3` 이 되지 않았는지 |
| 날짜 | `2026-02-24` |
| 수치 | `30초 → 10초`, `4.6MB → 2.6MB`, `15장` |
| 기능·옵션 이름 | `--interval`, `Cover`/`Contain`, `chromewebstore.google.com` |
| 링크 | URL 이 그대로인지 |
| 부정·조건 | "지원하지 않는다"가 "지원한다"로 뒤집히지 않았는지 |

어긋난 문장은 **그 문장만** 초고를 쓴다. 전체를 다시 윤문하지 않는다.

## 4. 문체

기존 블로그 글(`content/blog/releases/2026-08-05-swing-golf-1.2.md`,
`2026-08-11-screen-saver-extension-store-assets.md`)이 기준이다.

**쓴다**

- 담백한 평서문. 독자를 가르치려 들지 않는다
- 구체적인 숫자와 이름. "많이 빨라졌다"가 아니라 "30초에서 10초로"
- 왜 만들었는지를 먼저. 무엇을 만들었는지는 그다음
- 불편했던 상황을 그대로 적는 것. "반년 동안 멈춰 있었다"처럼

**쓰지 않는다**

| 금지 | 왜 |
|------|-----|
| `feat:`·`fix:`·`chore:` 프리픽스 | 커밋 로그를 옮긴 표시다 |
| 커밋 제목을 그대로 쓴 `###` 기능 제목 | 옛 글들을 changelog 로 만든 원인 |
| "혁신적인", "완벽한", "강력한" | 근거 없는 형용. 무엇이 어떻게 좋아졌는지 쓴다 |
| "사용자 경험을 개선했습니다" | 무엇이 어떻게 달라졌는지가 없다 |
| 지키지 못할 다음 계획 | `What's Next` 는 "미정"을 허용한다 |
| 검증 로그 (`bun run build passed`) | 릴리즈 노트 재료가 아니다 |
| 로컬 절대 경로 (`/Users/...`) | 게시되면 개인 경로 노출이다 |

## 5. 게시 전 확인

```bash
grep -c "TODO(" <파일>          # → 0   사람이 채울 자리가 남았는지
grep -c "{{" <파일>             # → 0   미치환 placeholder
grep -c "SOURCE(원본" <파일>    # → 0   근거 주석 삭제했는지
grep -cE "^- (feat|fix|chore|refactor|perf|docs|style)(\(.+\))?:" <파일>   # → 0
grep -c "/Users/" <파일>        # → 0   개인 경로
```

`draft: true` 를 지우는 것이 마지막이다. 그 전에 위 다섯 개가 모두 0이어야 한다.
